# Using MR Command Center Case Packs

Case packs are digital learning files imported into the browser-local **Pack Library**.

## Install a delivered pack

1. Obtain the `.json` case-pack file from the publisher or commerce/delivery platform.
2. Open MR Command Center.
3. Open **Pack Library**.
4. Choose **Install pack** and select the delivered file.
5. Open or resume the pack from its library card.

Pack content, completion history, and resume state stay in the local browser profile unless explicitly exported or cleared.

## Resume and progress

Pack Library tracks unique completed cases for each stable pack ID and remembers the last unfinished case when possible.

The **Study route** button creates a guided session from the unique MRCC modules represented by the pack.

## Updating a pack

Use **Update file** on an imported pack card.

The update file must use the same **stable pack ID**. When case IDs are also kept stable, compatible case-completion history remains associated with those cases.

The edition label is descriptive and helps the buyer identify the installed revision; MRCC does not contact a remote catalog to discover updates automatically.

## Licensing boundary

**Installed does not mean licensed.**

MR Command Center's static Pack Library does not verify purchase, ownership, subscription status, entitlement, or license validity. The seller's commerce/delivery system is responsible for customer access, payment, licensing terms, refunds, and file delivery.

Do not rely on Pack Library state as proof of purchase.

## Content boundary

Imported packs are user/vendor-supplied educational content and are not clinically validated by MR Command Center. Verify source material, manufacturer information, local policy, copyright/licensing rights, and other relevant requirements before relying on or distributing a pack.

Do not include patient identifiers or PHI in case-pack content.
